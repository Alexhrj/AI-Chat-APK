## 来源与状态 | Sources and Statuses

来源仅用 User Test / Official / Third-party；没有可引用来源时写“—”，它不是第四类来源。状态独立使用 Tested / Partially Tested / Not Tested / Needs Verification / Unknown，定义见指南。
Use only User Test / Official / Third-party as source labels. “—” means no attributable source, not a fourth source type. Independently use Tested / Partially Tested / Not Tested / Needs Verification / Unknown; definitions are in the guide.

历史 E1–E4 不再作为等级使用：E1 Official 对应 Official；E2 Hands-on 对应 User Test；E3 对应 Third-party；E4 Unconfirmed 必须根据实际情况设定状态，不是来源。迁移不代表重新验证，旧记录保留于 Git 历史。
Legacy E1–E4 are retired as levels: E1 Official maps to Official; E2 Hands-on to User Test; E3 to Third-party. E4 Unconfirmed requires a case-specific status, not a source label. Migration is not re-verification; prior text remains in Git history.

## 更新与证据原则 | Updates and Evidence

- 不把未观察到写成不存在，不把未知写成不支持。
  Do not turn not observed into nonexistent, or unknown into unsupported.
- 官方声明不等于实测；用户实测不代表所有版本、地区或账号。
  Official claims are not hands-on tests; user tests do not cover every version, region, or account.
- 保留官方与实测冲突的双方记录和环境，不静默覆盖。
  Preserve conflicting official and test records with their environments; do not silently overwrite either.
- 功能、版本、设置、收费或渠道变化时新增核查记录，保留历史观察。
  Add review records when features, versions, settings, pricing, or channels change; preserve historical observations.

简体中文

关于本数据库

本目录用于记录 Android AI 聊天应用的实际测试结果，包括 AI 伴侣、角色扮演、角色聊天及通用 AI 助手等应用。

数据库采用两层展示方式：

- 实测总览（Overview）：通过表格快速比较不同应用。
- 独立实测档案（Detailed Profiles）：为每款应用保存更完整的测试记录。

测试范围包括 NSFW 能力、功能、聊天体验、收费模式、公开内容、标签、隐私与安全等方面。

记录原则

1. 区分实测与官方信息：实际观察标记为“用户实测 / User-reported test”；官方信息应附官方来源。
2. 记录测试环境：尽可能记录测试日期、应用版本、设备平台、账户设置及地区。
3. 分别记录不同能力：私人对话生成、公开展示、内容审核提示、NSFW 设置和标签系统不得混为一谈。
4. 避免过度推断：未测试标记为“未测试 / Not tested”；无法确认标记为“未知 / Unknown”。
5. 及时更新：功能、政策和订阅价格可能变化，每条记录都应保留测试日期。
6. 尊重隐私与安全：不公开个人账户信息或其他用户的敏感资料。

English

About This Database

This directory documents hands-on testing of Android AI chat applications, including AI companions, roleplay, character chat, and general-purpose AI assistants.

The database uses two complementary presentation layers:

- Test Overview: A comparison table for quickly reviewing multiple applications.
- Detailed Profiles: Individual records containing more complete test results for each application.

Testing covers NSFW capabilities, features, chat experience, pricing, public content, tags, privacy, and security.

Documentation Principles

1. Separate hands-on observations from official information. Label personal observations as “User-reported test” and cite official sources for developer statements.
2. Record the test environment. Include the test date, app version, platform, account settings, and region whenever possible.
3. Keep different capabilities separate. Private chat generation, public content display, content warnings, NSFW settings, and tag systems must be documented independently.
4. Avoid unsupported conclusions. Use “Not tested” for untested items and “Unknown” when information cannot be confirmed.
5. Keep records current. App features, policies, and subscription prices may change; every test record should include a date.
6. Respect privacy and safety. Do not publish personal account information or other users' sensitive data.

Testing Status

- Tested: Supported by hands-on testing records.
- Partially tested: Only selected features or scenarios have been tested.
- Not tested: No hands-on testing has been performed.
- Needs verification: Information exists but lacks sufficient evidence.
- Unknown: No reliable information is currently available.

Evidence Labels

- User-reported test: Observations from actual use.
- Official source: Developer websites, official help centers, or official policies.
- Third-party source: App stores, independent reviews, or other public references.

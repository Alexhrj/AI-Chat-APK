下载与安全 | Download & Security

1. 优先使用开发者官方网站或官方应用商店。
2. 不将未知来源的修改版 APK 标记为官方版本。
3. 安装前检查应用权限、开发者信息和数字签名。
4. 有条件时核对 SHA-256 文件校验值。
5. 发现失效或可疑链接时，请提交 Issue。

## 记录规则 | Record Rules

- 来源：User Test / Official / Third-party。来源不等于核实状态。
  Sources: User Test / Official / Third-party. Source is separate from verification status.
- 核实状态：Tested / Partially Tested / Not Tested / Needs Verification / Unknown。
  Verification statuses: Tested / Partially Tested / Not Tested / Needs Verification / Unknown.
- 表中 Partially Tested 表示应用整体覆盖有限；逐项状态见档案。Unknown 不是不支持。
  Overall Partially Tested means limited coverage; profiles provide per-item statuses. Unknown does not mean unsupported.
- 未观察到不等于不存在；公开样本未见成人描写不证明已实施过滤。
  Not observed does not mean nonexistent; clean public samples do not establish filtering.
- 停止维护属于独立维护状态，不属于核实状态。目前三款应用的维护状态均未知。
  Discontinued is a separate maintenance status, not a verification status. Maintenance status is unknown for all three applications.

## 收录原则 | Listing Principles

优先收录 Android 应用；优先提供已核实的官方网站或开发者渠道；未知信息保留 Unknown；不提供未经授权的 APK 镜像；定期复查下载链接。
Prioritize Android applications and verified developer-controlled channels. Leave unknown information Unknown, do not provide unauthorized APK mirrors, and periodically recheck download links.

当前三款应用的开发者、官方渠道及可复现测试环境尚待核实，不猜测填充。
Developers, official channels, and reproducible test environments for these three applications remain to be verified; do not guess them.
